# Nicolás Fernández — Portfolio

Portafolio personal de servicios freelance: agentes de IA para WhatsApp, aplicaciones web full-stack e integraciones.

**En vivo:** <https://nico-fer.github.io/portfolio/>

## Qué ofrezco

- **Agentes de IA & chatbots** — atención y venta 24/7 por WhatsApp, integrados con CRMs y la API oficial de WhatsApp Business.
- **Aplicaciones web full-stack** — portales, dashboards y sistemas internos hechos a medida.
- **Integraciones & automatizaciones** — webhooks, APIs y conexión entre sistemas existentes.
- **APIs & backends** — diseño e implementación de APIs REST y bases de datos.

## Tecnología

HTML, CSS y JavaScript puros, sin framework ni proceso de build. Tipografías: Manrope, DM Sans y DM Mono (Google Fonts).

## Desarrollo local

Abrir `index.html` directamente en el navegador.

## Publicación

Despliegue automático en GitHub Pages desde `main` mediante `.github/workflows/pages.yml`.
